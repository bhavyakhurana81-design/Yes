# GreenPad – phone as Bluetooth TV controller
Pad, key mapping, custom HUD, two joysticks (left = arrows, right = mouse), admin/user roles.
## Get the APK (upload the files from INSIDE this folder to the repo top level)
1. Create a GitHub repo, upload all these files (keep the `.github` folder).
2. Open **Actions > Build APK > Run workflow** (also runs on every push).
3. Download **GreenPad-APK** from the finished run, unzip, install `app-debug.apk`.
## Use
1. Open app > Players tab > **Register as controller**.
2. On the TV: Bluetooth settings > add accessory > pick your phone and pair.
3. Back in the app, tap your TV in the list > **Connect**. Needs Android 9+.
